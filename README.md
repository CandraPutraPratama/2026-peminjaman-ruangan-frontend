# 2026-peminjaman-ruangan-frontend

## Description
Interface pengguna untuk Sistem Peminjaman Ruangan Kampus.

## Key Features
- Interactive Room List: Liat daftar ruangan yang tersedia lengkap dengan detailnya.
- Booking Form: Form peminjaman yang user-friendly dengan validasi real-time.
- Status Dashboard: Pantau status pengajuan (Pending, Approved, Rejected) secara visual.

## Tech Stack
- Library: React.js 
- Language: TypeScript 
- Tooling: Vite/CRA (sesuaikan nanti)
- Styling: CSS Modules/Tailwind CSS (Opsional)
